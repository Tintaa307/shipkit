# Pack 1 — Spec-Driven Development

Decide before you code: a human approves a spec, then a team of agents implements it slice by slice.

**Skills:** `new-feature` (idea → approved spec → slices), `implement-slice` (slice → PR).
**Agents:** `explorer` (impact map), `implementer` (code + tests), `verifier` (checks), `reviewer` (clean-context review, optional adversarial mode and mutation experiments), `searcher` (cheap Haiku lookups).

Install: `./install.sh 1` from the repo root.
